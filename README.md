# Anthology Hub — Public Demo

A sanitized, interactive portfolio edition of a larger literary learning platform.

## Live demo

GitHub Pages serves `index.html` from the repository root.

## What this demo shows

- focused digital reading workspace
- colour-coded annotation and evidence collection
- interpretation and concept-evidence notes
- browser-local persistence
- responsive student-facing interface
- privacy-conscious public-demo architecture

The demonstration uses an original sample text and synthetic/demo content only. It contains **no school data, student data, production IDs, credentials, private deployment configuration, licensed anthology text, or production Git history**.

The production concept was built around Google Apps Script/HTMLService with teacher visibility and structured student responses; this public edition intentionally keeps data local to the browser so it can be explored safely without authentication or backend credentials.
